Authentication / Authorization / Token

  • Authentication: None at the message/application layer. security mode="Transport" with clientCredentialType="None" means security relies solely on the HTTPS/TLS channel (the https:// address). No username/password, NTLM, bearer token, or client certificate is configured for this endpoint.
  • Authorization token / token id: No token is sent. Unlike other bindings in the same config (e.g. ws2007FederationHttpBinding with BearerKey, or Ntlm bindings), the Notification endpoint is clientCredentialType="None". The only identity-like value passed is the tenantId string in the SOAP body (a routing/tenant discriminator, not an auth credential).
  • Evidence: The call site passes requestor.TenantId only — no credential object — confirming no auth token is attached (NotificationHandler.cs, NotificationSender.cs).
